# 职衡 RoleFit AI Web Design System

本文件只约束 `frontend/web/` 的桌面端界面。业务事实与接口设计仍以仓库根目录的 `DESIGN.md` 和 `docs/design/` 为准。

## 1. 设计目标

- 品牌定位：AI 人岗匹配与智能面试平台，服务候选人与招聘团队两类用户；中文品牌为“职衡”，英文品牌为“RoleFit AI”，标语为“看见能力，衡量匹配”。
- 产品气质：简约、柔和、可信，但不是无差别的浅色卡片堆叠。品牌页强调黑、白与职衡红的强叙事，登录后的工作台保持安静、专业和高效。
- 使用效率：核心任务、状态和下一步操作应能快速扫描。
- 视觉来源：借鉴 Apple 的单一动作色、明暗表面交替、内容宽度锁定和低阴影策略，结合 Swiss Editorial Grid 的非对称布局、南孚官网的黑白红品牌表达，以及专业工作台的信息密度。
- 页面构图：先按业务流程设计信息架构，再落到组件；禁止只替换颜色、圆角和间距而保留旧页面拓扑。
- 当前范围：桌面 CSS 视口 `1280x720` 至 `3840x2160`；移动端暂不作为验收范围。

## 3. 字体与层级

- 字体栈：`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 页面标题：28-34px / 600 / 1.2-1.25，仅在页面或当前任务层级使用。
- 区块标题：18px / 600 / 1.35。
- 正文：15px / 400 / 1.6。
- 辅助文字：13px / 400 / 1.5。
- 按钮：14-17px / 400-600；标签：11-13px / 400-600。
- 只对编号、ID 和统计数字使用等宽字体；界面标签和步骤说明使用系统无衬线字体。
- 所有字间距保持 `0`，不随屏幕宽度缩放字号。

## 4. 间距、圆角与层级

- 结构间距使用 `4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64px`。
- 普通工具控件使用 8px 圆角，主动作可使用胶囊形；工作台分区默认无圆角，状态徽标仅在语义需要时使用胶囊形。
- 普通卡片、按钮和标题不使用投影；仅弹窗、下拉菜单等浮层允许轻投影。
- 页面区块优先使用留白、发丝分隔线和明暗表面切换建立层级；表面变化本身就是层级，不为每个区块创建浮动卡片。

## 5. 桌面布局

| CSS 视口 | 内容策略 |
| --- | --- |
| `1280-1599px` | 最大内容宽度 1440px，左右留白 24px |
| `1600-2559px` | 最大内容宽度 1520px，左右留白 32px |
| `>=2560px` | 最大内容宽度 1680px，左右留白 40px |

- 页面不能出现横向滚动。
- 长页面允许纵向滚动；粘性操作栏不得遮挡正文。
- 4K 屏幕通过内容最大宽度保持可读性，不把文字、表单或表格无限拉宽。
- 固定格式控件使用明确的网格轨道和最小高度，加载、选中和错误状态不能导致布局跳动。
- 核心桌面任务优先使用 12 列概念网格和非对称轨道。面试配置采用步骤轨 / 编辑区 / 实时简报三栏结构，三栏直接相邻并以 1px 分隔。
- `1280px` 下允许压缩侧栏，但主编辑区不得小于 640px；`>=2560px` 只增加内容宽度与留白，不放大正文字号。

## 6. 组件规则

- 顶部导航：64px 高、细底边；管理页面与面试配置使用白色半透明表面，首页使用深色上下文，当前位置必须清晰可见。
- 页面头部：一个主标题、一句必要上下文、最多一个主要操作。
- 选择项：整行可点击，以 grouped list 和柔和发丝线组织；选中时使用浅红背景和明确勾选图标，不使用高对比信号条。
- 多步骤任务：左侧步骤轨负责切换，中间一次只编辑一个步骤，右侧简报实时汇总并承载唯一最终操作。
- 流程选择：使用连续时间线或顺序行表达固定先后关系，不使用一组彼此孤立的复选卡片。
- 表单控件：桌面高度不低于 40px，主操作不低于 44px；必须保留可见标签和焦点环。
- 空状态：说明缺少什么，并提供唯一恢复操作。
- 加载状态：保持目标区域尺寸稳定；超过 300ms 使用骨架或明确加载反馈。
- 错误状态：说明失败内容并提供重试路径。
- 动效：150-220ms，仅使用颜色、透明度和轻微位移；遵守 `prefers-reduced-motion`。

## 7. 禁止事项

- 不复制 Apple 的摄影优先全屏产品页结构到业务工作台；Apple 只作为克制、留白与低阴影的设计原则来源。
- 不混用多个主色、随机圆角和随机阴影。
- 不用光斑、装饰性渐变和大面积 3D 场景承载核心任务。
- 不把所有内容包进独立卡片，也不在卡片中继续嵌套卡片。
- 不把旧页面的卡片原样换成带边框的 `section`；信息架构未变化时不视为完成视觉重构。
- 不在工作流页面并排放置多个同权主按钮；最终提交动作只能出现一次。
- 不用占位符替代字段标签，不移除键盘焦点样式。

## 8. 桌面验收

- 视口：`1280x720`、`1536x864`、`1920x1080`、`2560x1440`、`2560x1600`、`3840x2160`。
- 检查：无横向滚动、导航与主操作可用、文本不截断、表单和弹窗不越界、焦点可见、加载与错误状态不跳动。
- 4K 下页面保持合理阅读宽度；1080p 和系统缩放后的较小 CSS 视口仍可完成核心流程。

## 9. 页面体系与兼容入口

- `/` 是职衡品牌首页，使用黑、白、职衡红和真实产品界面构成首屏；品牌首页不复用登录后工作台的顶栏。
- `/resume`、`/position`、`/interview/*`、`/history`、`/profile` 是候选人工作台，共享 `AppLayout`、页面标题层级与 Element Plus 主题。
- `/admin/*` 是招聘治理与运营工作台，使用炭黑侧栏、浅色内容区、紧凑工具栏和无外层卡片的数据表格。
- `/login`、`/register` 使用统一的黑白双栏认证框架；认证成功后进入 `/resume`，不返回品牌首页。
- `/home-legacy` 仅作为旧首页兼容快照保留，不作为后续视觉开发基线。
