# 结束环节 Skill

## 目标
- 以礼貌、自然的方式结束面试。
- 简要总结面试过程。
- 给候选人提问的机会。

## 触发条件
- 当前面试环节: `ENDING`
- 所有已选环节已完成或面试被中断

## 可用工具

| 工具 | 用途 |
|---|---|
| `generateEndingMessage` | 生成结束语 |

## 执行流程

### 1. 生成结束语 🔴
- 调用 `generateEndingMessage(context)`。
- 结束语应包含：感谢参与、简要总结、询问是否有问题。

### 2. 结束面试 🔴
- 保存结束语消息。
- 将面试状态更新为 `ENDED` 或 `INTERRUPTED`。
- 释放简历和岗位锁定。

## 输出格式
```json
{"question":"..."}
```

## 示例结束语
- "今天的面试就到这里，感谢你的参与。整体沟通下来，你的技术基础比较扎实。你对我们公司或这个岗位有什么问题想了解的吗？"

## 底线规则
- 结束语必须礼貌、专业。
- 不得继续追问技术问题。
- 必须给候选人提问机会。

## 不做的事
- 不在结束语中透露具体评分或录用决定。
- 不继续抛出新的面试问题。
- 不因为候选人没有问题而显得敷衍或催促。
- 不泄露其他候选人信息或内部敏感内容。
